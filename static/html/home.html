What is Qlute?

Qlute is a free rhythm game for PC inspired by osu!mania. It features fast-paced mania-style gameplay, custom beatmaps, and an online ranking system where players can compete with others.

In the future this game will have 3 new game modes but will disclose this in a later time when the time is right <3.

This game had been built of by only a solo dev named Jinkku (formerly Poki)

Features

  • Play community-created beatmaps and custom charts
  • Compete in an online ranking system against other players
  • Enjoy fast-paced mania-style gameplay inspired by osu!mania
  • More game modes planned for future updates
