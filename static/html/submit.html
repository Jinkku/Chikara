Submitting beatmaps
  • Beatmaps are submitted from the game: right-click a set in song select and pick Submit to Qlute, or use File → Submit to Qlute in the editor.
  • Submitting the same set again updates it, until it's ranked.
  • Only osu!mania 4K difficulties are kept. Your sets start as Unranked; the Qlute team decides what gets ranked.
  • Open one of your beatmaps below to edit its title, artist, tags and difficulty names.
